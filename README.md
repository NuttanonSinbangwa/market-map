# แผนที่ตลาดอุ๊ยเก๊อะ (Interactive Market Map)

เว็บแผนที่ตลาดแบบอินเทอร์แอคทีฟ สร้างด้วย **Next.js (App Router) + React + TypeScript + SVG**
ไม่พึ่งไลบรารีแผนที่ภายนอก — ซูม/แพนเขียนเอง จึงเบาและปรับแต่งได้เต็มที่

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:3000
npm run build && npm start   # โหมด production
```

ต้องใช้ Node.js 18.18 ขึ้นไป

## ฟีเจอร์

- **แผนที่ SVG** แสดงโซน ทางเดิน แผงค้า 40 แผง และจุดบริการ (ทางเข้า, ห้องน้ำ, ATM, ที่จอดรถ)
- **ซูม/แพน**: ล้อเมาส์, ลากเมาส์/นิ้ว, pinch สองนิ้วบนมือถือ, ปุ่ม + − ⟲, กด `Esc` เพื่อรีเซ็ต
- **ค้นหา** ตามชื่อร้าน สินค้า รหัสแผง (เช่น `C03`) หรือชื่อโซน — แผงที่ไม่ตรงจะจางลง
- **กรองหมวดสินค้า** เลือกได้หลายหมวด และตัวเลือก "เฉพาะร้านที่เปิดอยู่ตอนนี้"
- **สถานะเปิด/ปิด** คำนวณจากเวลาเครื่องผู้ใช้ + วันหยุดของแต่ละร้าน (จุดสีเขียว/เทา)
- **คลิกแผง** → ซูมไปที่แผงอัตโนมัติ + แสดงรายละเอียดด้านข้าง
- **แชร์ลิงก์** ไปยังแผงเฉพาะ เช่น `/?stall=C03`
- Tooltip เมื่อเอาเมาส์ชี้, รองรับคีย์บอร์ด (Tab / Enter) และ `prefers-reduced-motion`
- Responsive: เดสก์ท็อปเป็น sidebar ซ้าย, มือถือเป็นแผงด้านล่าง

## โครงสร้างไฟล์

```
app/
  layout.tsx, page.tsx, globals.css
components/
  MarketMap.tsx    # state หลัก: ค้นหา/กรอง/เลือก/URL
  MapCanvas.tsx    # วาด SVG: โซน แผง จุดบริการ
  Sidebar.tsx      # ค้นหา ตัวกรอง รายการร้าน
  StallDetail.tsx  # การ์ดรายละเอียดแผง
hooks/useZoomPan.ts  # ซูม/แพน/pinch/focus
data/market.ts       # ข้อมูลทั้งหมดของตลาด (แก้ที่นี่)
lib/status.ts        # คำนวณเปิด/ปิด
```

## แก้ไขเป็นข้อมูลตลาดจริง

ข้อมูลใน `data/market.ts` เป็น **ข้อมูลตัวอย่าง** ให้แก้ที่ไฟล์นี้:

- `MAP` ขนาดผืนแผนที่ (หน่วย viewBox)
- `ZONES` ตำแหน่ง/ขนาดโซน
- `POIS` จุดบริการ
- `CATEGORIES` หมวด สี ไอคอน และเวลาเปิดมาตรฐาน
- `STALLS` สร้างจากฟังก์ชัน `build(zone, หมวดเริ่มต้น, รายการ)` ที่จัดเรียง 5 แผง/แถว อัตโนมัติ
  แต่ละแผงกำหนด `hours`, `closedDays` (0 = อาทิตย์), `note`, และ `cat` เพื่อ override ได้

ถ้าผังตลาดไม่ได้เป็นตารางสม่ำเสมอ ให้เขียนแผงเป็นออบเจ็กต์ `{ id, x, y, w, h, ... }` ตรง ๆ แทน `build()`
หรือจะโหลดจาก API/CMS แล้วส่งเป็น props ก็ได้

## แนวทางต่อยอด

- เส้นทางเดินจากทางเข้าไปยังแผงที่เลือก (A* บน grid ของทางเดิน)
- โหลดข้อมูลจาก Google Sheets / Supabase / headless CMS
- ใช้พื้นหลังเป็นแปลนจริง (`<image>`) ใต้ชั้นแผง
- หน้าแอดมินสำหรับลาก-วางแก้ตำแหน่งแผง
